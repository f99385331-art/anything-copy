Anything Copy v0.1（给朋友的一页说明）
=====================================

这是什么
  一个"看懂任意软件/网站，然后帮你做出自己版本"的桌面工具。
  基于开源项目 Craft Anything（ArtCraft 团队）的 fork，代码 MIT/Apache-2.0。
  本包已换成 Anything Copy 的名称与图标；上游商标权利归其所有者。

怎么装
  1. 解压本 zip 到一个文件夹（不要放在中文/空格路径也没关系，路径别太深即可）。
  2. 双击「启动 Anything Copy.bat」（或直接运行 craft-anything.exe）。
  3. Windows 若弹蓝色 SmartScreen：点「更多信息」→「仍要运行」（程序没有花钱签的证书，正常现象）。
     首次运行会在 文档\Anything Copy\ 建项目文件夹。

第一次用
  - 设置(AI) 里添加你自己的编码代理（如 Hermes Agent）和模型服务商的 API key。
  - ⚠️ 如果你之前用过旧版 Craft Anything：API key 存在新名字下，需要在这里重新填一次。
  - 贴一个网址或软件名，它先"研究"再"构建"，进度都在左侧日志里。

已修复的坑（相对上游 0.5.0）
  · 限流(429)不再冒充"余额用尽"，等一分钟自动续跑，不再一夜白烧额度
  · 大任务书超长被 Windows 掐死的报错，现在会说人话
  · 暂停不再留僵尸进程；两个构建不会同时抢一个项目
  · 构建对话有预算熔断：反复失败会停下来问你，而不是一直烧

已知限制
  · exe 文件名仍是 craft-anything.exe（包内部机器名，v0.2 统一改）
  · Mac 版图标(.icns)未换（不影响 Windows）
